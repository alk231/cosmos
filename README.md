# Cosmos: A Journey Through Indian Space History 🚀

A web-based educational project that chronicles the history and milestones of space research in India. This interactive website takes users on a journey from the formative years of the Indian space program to the modern 21st-century achievements.

## 🌌 Overview

"Cosmos" acts as a digital timeline, guiding visitors through different eras of India's space exploration saga. The website is structured into distinct historical phases, each offering detailed insights and visual media.

## 📚 Sections

The website is divided into chronological sections:

- **Formative Years**: Explores the roots of Indian space research in the 1920s, the establishment of INCOSPAR, and the early experiments with sounding rockets.
- **1970s and 1980s**: Covers the era of major satellite launches and the solidification of ISRO's capabilities.
- **1990s**: Highlights the technological advancements and the operationalization of launch vehicles.
- **21st Century**: Showcases modern achievements, including lunar and interplanetary missions.
- **Explore**: A multimedia section featuring video content (`fifth.html`).

## 🛠️ Tech Stack

- **HTML5**: For semantic structure and content organization.
- **CSS3**: For custom styling, layout, and visual aesthetics.
- **Swiper.js**: Utilized for creating responsive and touch-enabled image sliders/carousels to display historical photos.
- **Google Fonts**: Uses 'Poppins' for modern and readable typography.

## 🚀 How to Run

1. **Clone the repository**
   ```bash
   git clone https://github.com/alk231/cosmos.git
   ```

2. **Open the project**
   - Navigate to the project directory.
   - Open `index.html` in any modern web browser (Chrome, Firefox, Edge, Safari).

## 📂 Project Structure

- `index.html`: The landing page with navigation cards for different historical eras.
- `first.html` - `fourth.html`: Content pages corresponding to specific time periods (Formative years, 70s-80s, 90s, 21st Century).
- `fifth.html`: Video/Explore page.
- `style*.css`: Stylesheets for different pages and components.
- `*.js`: Scripts for interactivity, including Swiper initialization.
